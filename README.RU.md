# 🎮📼 Оффлайн-Каталог

<br>

</div>

Оффлайн-каталог для игр, фильмов и любых файлов на носителях (флешки, внешние HDD и т.д.). Кладёшь папки с архивами на носитель, запускаешь сканер, и получаешь **один** `index.html` который открывается двойным кликом в браузере без интернета, и показывает каталог с обложками, описаниями, категориями и поиском.

Идея: собрать архив один раз, а потом в любой момент без интернета и без установки софта — открыть и увидеть, что лежит на носителе в удобном виде и с описанием.

***

## 📋 ПО требуемое для создания архива

### Обязательно

- **Python 3.7+**
- **Bash** (Linux, macOS; на Windows — WSL или Git Bash)

### Рекомендуется

- **Pillow** — для нарезки обложек и скриншотов:

```bash
python3 -m pip install Pillow
```

Без Pillow каталог создаётся, но без обложек и превью — только названия и текст.

- **zenity или whiptail** — для графического интерфейса лаунчера запускающего программу сканирования.

Без них используется обычный терминальный `select` (работает всегда).

```bash
sudo apt install zenity        # Debian/Ubuntu GUI
sudo apt install whiptail      # TUI в терминале
```

## 🚀 Быстрый старт

### 1. Установить зависимости

```bash
python3 -m pip install Pillow
sudo apt install zenity         # или whiptail
```

### 2. Разложить архивы на носителе

Единственный поддерживаемый формат:

```text
<носитель>/
├── Игры/
│   └── Baldurs Gate 3/
│       ├── Baldurs Gate 3.zip         ← архив или любой файл
│       └── info/                       ← метаданные (создастся сам)
│           ├── info.txt
│           ├── cover.jpg
│           └── screenshots/
│               ├── scr_1.jpg
│               └── scr_2.jpg
├── Фильмы/
│   └── Inception/
│       ├── Inception.mkv
│       └── info/...
└── Прочее/
    └── 7-Zip/
        ├── 7z2409-x64.exe
        └── info/...
```

**Правила:**

- В корне носителя только `Игры/`, `Фильмы/`, `Прочее/` (регистр и язык не важны — `игры`, `Games`, `games` — всё сработает).
- Внутри каждой категории — папки элементов (`Baldurs Gate 3`, `Inception`, `7-Zip`).
- В папке `info/` положить файл с метаданными `info.txt`, основную обложку `cover.jpg` и папку `screenshots/` со скриншотами. Если папки `info/` не создать, то сканер создаст ее сам но в метаданных будет минимальный набор описания.
- Внутри папки элемента — хотя бы один файл (архив, видео, exe — что угодно).
- Все остальные папки в корне пропускаются с предупреждением.
- Если структура другая — сканирование ничего не найдет.

### 3. Запуск сканера

Необходимо запустить лаунчер сканирования файл `scan.sh`.

```bash
./scan.sh
```

Появится меню:

1. **Выбор носителя.**
2. **Выбор языка** — Русский или English для интерфейса каталога (сами данные будут на том языке как они хранятся на носителе).
3. **Сканирование.**
4. **Открытие `index.html` в браузере.** — В браузере после завершения сканирования откроется вкладка с каталогом.

### 4. Что получится

На носителе появятся:

```text
<носитель>/
├── index.html              ← Каталог
├── catalog.md              ← Список элементов каталога в виде таблицы (если не требуется можно удалить)
├── .archive_thumbs/        ← thumb-скриншоты (системные данные)
├── Игры/
│   └── Baldurs Gate 3/
│       └── info/           
│           ├── info.txt
│           └── screenshots/
└── ...
```

`index.html` — Для просмотра каталога открывать этот файл.

## 📝 info.txt — что писать

Файл с метаданными объекта хранения лежит в `<элемент>/info/info.txt`. Если его нет, то сканер создаст шаблон с заполненными `Название, Категория, Год` (из имени папки, если там есть `2023` или `(2010)` и т.п.). Остальное не заполнится, и эти данные можно заполнить позднее вручную.

### Все поддерживаемые поля

| Поле | Пример | Куда попадает |
|---|---|---|
| Название | Baldurs Gate 3 | Заголовок карточки |
| Категория | Игры | Необязательно — берётся из папки |
| Жанр | RPG, Fantasy, Turn-based | Красная строка под названием |
| Год | 2023 | Чип в деталях |
| Описание | Продолжение легендарной серии... | Основной текст в деталях |
| Разработчик / Автор / Студия | Larian Studios | Детали |
| Издатель | Larian Studios | Детали |
| Режиссёр / Режиссер | Christopher Nolan | Детали (для фильмов) |
| Язык | Русский (текст), Английский (озвучка) | Чип |
| Версия | 4.1.1.3624 | Чип |
| Серия | Baldur's Gate | Детали |
| Страна | США, Великобритания | Детали |
| Длительность | 2 ч 28 мин | Чип (для фильмов) |
| Комментарий | Установлен русификатор. Патч 5  | Детали |

Ключи регистронезависимы (`Жанр`, `жанр`, `ЖАНР` — одинаково). Порядок строк не важен. Всё, что не совпало с ключом — игнорируется (можно писать заметки для себя).

### Примеры

**Игра:**

```text
Название: Baldurs Gate 3
Жанр: RPG, Fantasy, Turn-based
Год: 2023

```

**Фильм:**

```text
Название: Inception
Жанр: Sci-Fi, Thriller
Год: 2010
Режиссёр: Christopher Nolan
Страна: США, Великобритания
Длительность: 2 ч 28 мин
Язык: Английский (оригинал), Русский (дубляж)

```

**Софт:**

```text
Название: 7-Zip
```

## 🖼️ Обложки и скриншоты

### `info/cover.jpg` — обложка

Положите `cover.jpg` (или `cover.png`, `cover.webp`, `poster.jpg`) в `info/`. Сканер сконвертирует его до размеров 160×213 и добавит как base64 в `index.html`.

Оптимально — вертикальная обложка 2:3 (например, 500×750).

### `info/screenshots/` — скриншоты

Положите любые `.jpg`/`.png` в `info/screenshots/`. Сканер сделает thumb в размере 320×200 в `.archive_thumbs/`.

Скриншоты отображаются только на десктопных браузерах в карточке деталей (кликаются → лайтбокс). На мобильных браузерах скриншоты не отображаются из за ограничений android и оптимизации размера файла каталога `index.html`.

***

## 📄 info.json — альтернатива

Если `info.txt` не хватает (например, нужны переносы строк в описании) — создайте `info.json`:

```json
{
  "name": "Baldurs Gate 3",
  "genre": "RPG, Fantasy, Turn-based",
  "year": "2023",
  "description": "Продолжение легендарной серии.\n\nОсобенности:\n• 3 акта\n• Кооператив до 4 человек",
  "comment": "Проверено на HDD #3"
}
```

`info.json` приоритетнее `info.txt` — если лежат оба, читается JSON.

## ⚙️ Флаги запуска scan.sh

```bash
./scan.sh [опции]
```

| Флаг | По умолчанию | Что делает |
|---|---|---|
| --root PATH | спросит через меню | Сканировать PATH без меню выбора носителя |
| --label NAME | метка диска | Метка носителя (в шапке каталога) |
| --title TITLE | HARD ARCHIVE | Заголовок каталога |
| --output FILE | index.html | Имя выходного файла |
| --lang ru\|en | спросит через меню | Язык интерфейса без вопроса |
| --no-menu | — | Не показывать меню (ни носитель, ни язык). Язык = `ru` |
| --no-open | — | Не открывать браузер после сканирования |
|  --keep-open  | — | Пауза в конце (только из терминала; для отладки) |
| -h, --help | — | Справка |

### Примеры запуска лаунчера

```bash
# Самый простой запуск (всё спросит)
./scan.sh

# Скриптовый режим: указать носитель, метку, язык интерфейса
./scan.sh --root /media/user/USB64 --label "USB 64GB" --lang ru --no-open
```

## ⚙️ Флаги scan.py (если запустить сканер напрямую в PYTHON)

При необходимости можно запускать сканер напрямую без лаунчера и тогда появится возможность влиять на размер обложек и еще несколько других параметров.
Но как правило это не требуется.

```bash
python3 scan.py --root /media/user/USB64 --label "USB 64GB" --lang ru
```

| Флаг | По умолчанию | Что делает |
|---|---|---|
| --root PATH | папка скрипта | Что сканировать |
| --label NAME | пусто | Метка носителя |
| --title TITLE | по языку | Заголовок каталога |
| --output FILE | index.html | Имя выходного файла |
| --lang ru\|en | ru | Язык интерфейса |
| --thumbs-dir DIR | .archive_thumbs | Папка для thumb-скриншотов |
| --list-size WxH | 160x213 | Размер base64-обложки |
| --screenshot-size WxH | 320x200 | Размер thumb-скриншота |
| --quality N | 72 | JPEG-качество 1..95 |
| --no-thumbs | — | Не нарезать превью (быстро, но без картинок) |
| --keep-old | — | Не удалять старый index.html и .archive_thumbs/ |

## 🖥️ Просмотр на десктопе

Откройте `index.html` двойным кликом. Работает в Firefox, Chrome, Edge, Safari, устанавливать ничего не нужно.

Возможности:

- Наведение на элемент в списке → панель справа обновляется
- Клик → закрепить выбор (не сбрасывается, когда мышь уходит)
- Клавиатура: `↑`/`↓` — навигация, `Enter` — закрепить, `Esc` — снять закрепление
- `Ctrl+F` — фокус в поиск
- Поиск — по названию, жанру, описанию, разработчику, году
- Сортировка — название/год/размер, в обе стороны
- Категории — клик по табу `Игры`/`Фильмы`/`Прочее` фильтрует.
- Скриншоты — клик → полноэкранный лайтбокс
- Копировать путь — кнопка в карточке деталей. Это основное в программе: Копируете путь, вставляете его в менеджере файлов и переходите к требуемому элементу архива.

❓ **- Почему так сложно.**
Цель иметь красивый и удобный каталог используя только возможности браузера (который как правило есть везде) без необходимости установки какого либо ПО.
Но, прямо из браузера нельзя перейти к файлам в файловом менеджера так как это запрещено политикой безопасности, и поэтому копируем путь и вставляем в менеджере файлов.

## 📱 Просмотр в мобильном браузере (Android)

Каталог открывается в мобильном браузере, но с оговорками из-за политики безопасности Android.
Но каталог все же предназначен для использования с десктоп браузерами и на Android мало полезен.

### Что работает

- Открытие `index.html` например в Brave (сначала запустить Brave, потом тапнуть по файлу в файловом менеджере — «Открыть с помощью» → Brave).
- Просмотр списка, категорий, деталей, обложек, описаний.
- Переход «список → карточка → назад» (на узком экране смартфона показывается по одному экрану за раз).
- Поиск, сортировка.

### Что НЕ работает

- Скриншоты на мобильном скрыты (экономия размера `index.html`).
- Копирование пути на Android — не работает в большинстве файловых менеджеров из-за scoped storage (Android 11+). Менеджер сам не может перейти по скопированному пути — это его ограничение, не каталога. Кнопка в этом случае показывает «Android не позволяет использовать пути к файлам на USB». 


## 🔄 Обновление каталога

После того как вы добавили игру/фильм, обновили `info.txt` или положили новую обложку — запустите `scan.sh` ещё раз на том же носителе.

Что происходит:

- Удаляется старый `index.html` и `.archive_thumbs/`.
- Создаются новые.
- Файлы пользователя (архивы, `cover.jpg`, `screenshots/`, `info.txt`) никогда не удаляются и не перезаписываются.

## 🔍 Диагностика проблем

### «Каталог создаётся, но пустой» / «сканер ничего не нашёл»

Проверьте структуру:

- Должны быть `Игры/`, `Фильмы/` или `Прочее/`.
- Внутри каждой категории — папки элементов, в каждой папке — хотя бы один файл с расширением из списка:

```text
архивы: .rar, .zip, .7z, .iso, .tar, .tar.gz, .tar.xz,
        .tar.bz2, .tgz, .gz, .xz

видео: .mkv, .mp4, .avi, .m4v, .webm, .mov, .wmv,
       .flv, .mpg, .mpeg, .ts
```

Если ваши файлы с другим расширением — добавьте его в `scan.py` в константу `ARCHIVE_EXTS` или `VIDEO_EXTS`.

### Обложки не отображаются

- Проверьте, что `cover.jpg` лежит в `info/`, а не в корне папки элемента.

### `data.js` больше нет — это нормально

В старой версии сканер создавал `data.js` рядом с `index.html`. Теперь всё в одном `index.html`: данные и обложки вшиты внутрь. Это упрощает 

## 📂 Структура проекта

```
cold-archive/
├── scan.sh ← обёртка: меню, выбор языка, запуск scan.py
├── scan.py ← сам сканер: обход носителя, нарезка превью, генерация index.html
├── index_template.html ← шаблон каталога (HTML+CSS+JS).
└── README.md ← этот файл
```

### Что происходит при запуске

```
scan.sh
  ├─ меню выбора носителя (zenity/whiptail/dialog/select)
  ├─ вопрос про язык (zenity/whiptail/dialog/select)
  ├─ scan.py --root <носитель> --lang <ru|en>
  │    ├─ удаляет старый index.html и .archive_thumbs/
  │    ├─ находит Игры/, Фильмы/, Прочее/
  │    ├─ для каждого элемента:
  │    │    ├─ создаёт info/ если нет (info.txt + screenshots/)
  │    │    ├─ читает info.txt/info.json
  │    │    ├─ нарезает cover.jpg → base64
  │    │    └─ нарезает screenshots/*.jpg → .archive_thumbs/
  │    ├─ собирает JSON со всеми элементами
  │    ├─ подставляет JSON и языковые строки в index_template.html
  │    └─ пишет итоговый index.html
  └─ открывает index.html в браузере
```

## ❓ FAQ

**Можно ли открыть каталог на компьютере, где нет Python?**  
Да. `index.html` — полностью автономный файл. Python и Pillow нужны только для создания каталога. Для просмотра — только браузер.

**Можно ли положить обложки/скриншоты с расширением `.webp`?**  
Да, для cover — `.webp` поддерживается. Для скриншотов — `.jpg`, `.jpeg`, `.png`, `.webp`, `.gif`, `.bmp`. Pillow всё это открывает.

**Как добавить ещё одну категорию (например, «Музыка»)?**  
В `scan.py` в `CATEGORY_DIRS` добавьте:

```python
'music': 'Музыка', 'музыка': 'Музыка',
```

И в `index_template.html` в `CAT_LABELS` — перевод (или без него, будет отображаться как есть).

**Есть ли лимит на количество элементов?**  
Практически нет. На 500 элементов `index.html` весит ~4–6 МБ (с base64-обложками). Открывается за 1–3 сек на мобильном, мгновенно на десктопе. На 2000+ — заметно тяжелее, есть смысл подумать про `--no-thumbs` (только список без обложек) или разбить на несколько носителей с отдельными каталогами.

**Куда сканер пишет логи?**  
`/tmp/scan-YYYYMMDD-HHMMSS.log`. Это стандартная временная папка Linux, очищается при перезагрузке. Для постоянного хранения — копируйте оттуда вручную или добавьте в `scan.sh` свой `LOG_FILE`.
